# ⚔️ Perfect Reswap — ресвап для Perfect World

## ⚙️ Возможности

### 🎯 Точный ресвап:
Нажал скилл в Сет 2 (пение) — программа моментально наденет атакующий Сет 3 на время каста, а по окончании вернёт обратно в Сет 2. Никаких ручных свапов.

Скиллы кастуются **только из пение сета** — в защитном сете ресвап не срабатывает.

### 📋 Белый список скиллов
Сам выбираешь, какие скиллы запускают ресвап — остальные программа игнорирует. Для каждого скилла из списка настраивается:
- **Время каста** — сколько длится по времени каждое умение (легко настраивается)

### 🔒 Умная блокировка защитного сета
Нажал Сет 1 во время ресвапа? Программа не собьёт экипировку — запомнит нажатие и автоматически переключится в защитный сет. Никаких неловких моментов в разгар боя.

### 👁️ Визуальное определение активного сета
Один раз выделяешь область экрана для каждого сета — программа сама понимает, в каком сете ты находишься в любой момент.

### 📺 Оверлей поверх игры
Миниатюрное окно поверх всех окон показывает:
- Текущий активный сет (цветом)
- Пинг до сервера в реальном времени

Перетаскивается мышью, позиция сохраняется.

### 💾 Профили
Сохраняй конфигурацию под каждого персонажа — скиллы, клавиши, сервер. Переключение в один клик.

### 🔄 Автообновление
Встроенный апдейтер проверяет новые версии и обновляет программу автоматически.

### ⚠️ Ограничения
Программа работает только на серверах с **серверным свапом снаряжения**. Либо могут подойти внешние свап-программы, но это прямо влияет на качество ресвапа.

---

## 🚀 Быстрый старт

1. Выбери сервер и архитектуру клиента
2. Откалибруй 3 сета (выдели область экрана для каждого)
3. Добавь скиллы с нужным временем каста
4. Нажми **Старт**

*Настройка занимает ~10 минут.*
